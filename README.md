## 2. 快速开始

### 安装（一次性）

```bat
cd /d "D:\project\magic video"
python -m pip install -r requirements.txt
```

依赖仅 6 个：`pywebview`、`pythonnet`、`pystray`、`Pillow`、`requests`、`psutil`。
本机已实测安装完成（Python 3.13 / Node 22 / SQLite 3.53 / Edge WebView2 157）。

### 打包产物（目标机器无需 Python）

由 `build_dist.py` 一键生成：

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt pyinstaller
.venv\Scripts\python.exe build_dist.py
```

| 产物 | 位置 | 播放记录存哪 |
|---|---|---|
| 绿色版 ZIP | `dist/MagicVideo-<版本>-win64-portable.zip` | 解压目录内 `Magic Video/data/`（靠 `portable.txt` 标记） |
| MSI 安装版 | `dist/MagicVideo-<版本>-win64.msi` | `D:\magicvideo`（默认，可用 `MAGIC_VIDEO_DATA_DIR` 覆盖） |

- 绿色版解压即用；删掉 `portable.txt` 就切换到「安装版」的数据位置。MSI 为 **perUser 安装**（`%LOCALAPPDATA%\Programs\Magic Video`），双击即可安装、不需要管理员，带开始菜单快捷方式与卸载入口。
- 两种形态都只有 `Magic Video.exe` 一个可执行文件：主窗口、托盘守护（`--daemon`）、构建自检（`--selftest`）复用它；开机自启和托盘菜单会自动选择源码版或打包版的启动命令。
- **资源与数据分离**：网页、内置词典、文档随程序分发（只读），数据库单独放用户可写目录，升级或重装不会丢播放记录。可用环境变量 `MAGIC_VIDEO_DATA_DIR` 显式指定数据目录。
- 首次构建需联网下载 WiX 3.14 工具包（约 40 MB，落在 `build/tools/`），`build/` 与 `dist/` 均不入库。
- **升级安装**：直接双击新版 MSI 即可自动替换旧版；数据库在 `D:\magicvideo`（不在安装目录），播放记录完整保留。新版已关闭 WebView2 持久缓存并给 `app.js` 加版本串，避免升级后仍显示旧界面。
- **数据目录默认值**：源码版与打包版统一为 `D:\magicvideo`（`app/config.py::DEFAULT_DATA_DIR`），守护进程与开机自启也走同一默认值；`./start` 会显式 export 同一路径以便守护继承。旧 `%APPDATA%\Magic Video` 目录保留未删除，可随时回滚。

### 启动

| 操作 | 效果 |
|---|---|
| **`./start`（Git Bash，项目根目录）** | **推荐**：一键从源码打开主窗口，直接连**真实数据库**（`D:\magicvideo\library.db`） |
| `./start --local` | 改用项目内 `data/library.db` 的调试库，不碰真实记录 |
| `./start --debug` | 附带打开 DevTools |
| 双击 `dev.bat` | 调试入口：默认复制真实库成 `data/dev/library.db` 安全副本后启动；`dev.bat --real` 直接连真实库 |
| 双击 `start.bat` | 打开主界面（9 个功能页） |
| 双击 `start_daemon.bat` | 手动单独启动托盘常驻记录（无控制台窗口）；平时**不需要**用它 |
| 「设置」页 →「启动软件时自动开启后台记录」 | **默认开启**：打开主窗口即自动拉起托盘守护；关闭时立即停掉当前守护，再打开可立刻补拉起 |
| 「设置」页 →「开机自动启动后台记录」 | 写 `HKCU\...\CurrentVersion\Run`，无需管理员权限；与上一条互不影响 |

> **两个开关不一样**：`daemon_auto_start` 管「每次打开本软件时拉起守护」（默认开），`autostart` 管「登录 Windows 时自启」（默认关），`recording_enabled` 管「守护是否写历史」。三者互不覆盖。

> **数据库在哪**：`./start` / `start.bat` / 安装版默认用的是
> `D:\magicvideo\library.db`（D 盘，用户指定）。`./start` 启动时会把数据目录和 `.db` 完整路径打印出来。
> 绿色版若带 `portable.txt` 仍写解压目录下的 `data/`。
> 只有 `./start --local`、`dev.bat` 默认模式、`data/dev/` 才是调试副本；调试副本里导入/播放不会写进真实记录。
> 封面在 `<数据目录>\covers\`，日志在 `<数据目录>\logs\`，全部**只在本机**。
> 重复点任务栏图标不会再开第二个窗口：互斥锁检测到已有实例后只把旧窗口置前。

### 三步用起来

1. **导入列表** → 粘贴作品名，点「解析预览并匹配中文名」→ 中文名当场出现且可手改 → 点「确认导入」。
2. **添加视频目录** → 填入已下载视频所在文件夹 → 自动递归扫描，外文文件名当场转成中文名。
3. **继续观看** → 从列表点开任意一集，PotPlayer 以 `/seek=hh:mm:ss` 从上次位置启动；播放过程自动写入进度与会话。

> 即使不通过本工具、直接双击用 PotPlayer 打开视频，托盘守护也会记录（会用窗口标题建一条 `external` 占位记录）。
> 把该视频所在目录加进「扫描目录」后，续播即可正常使用。

### 全量文件列表与点击播放（v0.1.4）

「扫描目录」页的「扫描结果 · 全部文件」与「媒体库」页共用同一个列表组件：

- **不截断**：默认每页 200 条，可翻页 / 跳页，或选「一次显示全部」把库内文件一次列出（本机实测 2104 条）。
- **搜索**：文件名、中文名、解析原名、原始标题、完整路径；`%` / `_` / `\` 按字面量匹配。
- **筛选与排序**：按扫描目录、匹配状态（已匹配中文 / 未匹配 / 有播放进度）筛选；按最近扫描 / 文件名 / 中文名 / 文件体积 / 观看进度排序。
- **直接播放**：点文件名、缩略图或「播放」按钮即用 PotPlayer 打开（有断点自动续播），右侧另有「从头播放」。
- 搜索与筛选只局部刷新列表，不重建输入框，不会丢焦点；扫描完成后可用「刷新列表」取最新结果。

### 媒体库树状视图（0.1.4 日常迭代）

平铺列表把 2104 个文件一次铺开，很难看出「哪几集属于同一部、哪一季」。工具栏的**展示方式**可切换三种视图，搜索、目录筛选、匹配状态筛选在三种视图里都生效：

| 视图 | 层级 | 适用 |
|---|---|---|
| 作品 → 季 → 集（媒体库默认） | 作品 → 第 1 季 / 第 2 季 / 第 3 季 / 未标注季 → 每一集 | 追剧、追番；第一季第二季分别成组，十几集展开即可看到 |
| 目录树（扫描结果页更直观） | 扫描根目录 → 子文件夹 → 文件 | 按下载目录找文件、核对字幕组发布包 |
| 平铺列表（原视图） | 文件 → 文件 | 翻页 / 一次显示全部 / 按体积、进度排序 |

- **分组规则**：优先用已匹配到的干净中文名；字幕组命名的番（每集文件名都不同）以**发布目录名**归并，去掉分辨率、字幕组、集数范围、季标记等噪音；只有 ≥2 个文件的目录才作为分组依据，单文件电影不会被错并成一部剧。
- **季 / 集推断**：扫描解析出的 `season_no` / `episode_no` 优先；缺省时从 `Season 2`、`S2`、`第三季`、`[01]` 等文件名或目录名补齐。剧场版、特典等无固定季集的文件进「未标注季」，不会丢。
- **节点信息**：显示集数、已看 / 在看数与「播放下一集」（优先回到看了一半的那一集）；点击节点展开才渲染文件行，几千个文件也不会卡。
- 树状视图对**当前筛选结果的全部文件**分组，不受每页条数限制；搜索关键词时会自动展开命中的分组，结果太多时只展开第一层。

### 启动体验、剧集墙、快搜与软件内播放（0.1.4 日常迭代，未升版本）

这一批是按实际使用反馈补的，全部**不打包、不打 tag**，版本号仍是 `0.1.4`。

**启动与单实例**

- `app/single_instance.py` 用命名互斥锁保证只有一个主窗口；第二个进程只把已有窗口 `ShowWindow(SW_RESTORE)` + 置前，不再初始化第二个 WebView2（这正是之前启动卡顿和多窗口的来源）。
- `js_api` 只以 `_window` 私有属性持有 pywebview Window，避免 `dir()` 深度反射 .NET 控件树时刷 `CoreWebView2` 的 `E_NOINTERFACE` 报错；`webview.start(gui="edgechromium", private_mode=True)` 不再传 `background_color`。
- 读播放器状态改用 `SendMessageTimeoutW(..., SMTO_ABORTIFHUNG, 300ms)`，PotPlayer 忙时不会把 3 秒一次的界面轮询挂死。
- 设置存在 SQLite，窗口关闭后主题、窗口尺寸、开关都还在。
- **后台记录默认自动启动**：`app/main.py` 建好窗口后调用 `Api.ensure_daemon_auto_start()`，前端 `init()` 再做一次幂等兜底；已在运行或设置里关掉都不会重复拉起。左下角与「总览」的手动启动按钮已移除，只保留状态圆点。设置页关闭时会调用 `stop_daemon()` 立即停掉守护，重新打开则马上补拉起。`Api.__init__` 绝不启动进程，避免单测拉起真实守护。

**剧集墙与封面**

- 「剧集墙」参考 SeedHub / AGE动漫 做卡片式作品墙：封面、季数、集数、已看/在看、播放下一集。
- 点「后台抓取封面」才启动**一次性**后台线程（不是定时任务、不开机自跑）：主源 AGE动漫搜索页，备源 SeedHub 首页/分类页，按标题精确配对后下载到 `<数据目录>\covers\`，并把 `cover_url` / `cover_local` 写进 `subjects`。可随时「停止」，已有封面直接命中缓存不重复下载。
- 图片通过 `cover_data_uris()` 转成 data URI 给 WebView2 显示（不依赖 `file://` 权限）；单个异常只跳过，不影响整墙。
- 抓取顺序优先「剧集墙卡片标题」（与媒体库树同一套分组，保证抓到就能显示），其次导入清单中文名；`cover_key()` 会去掉季标记与尾集号，同一部番逐集分组只抓一张共用封面。脏英文文件名、番号编号与「（完）」残行会被过滤，避免把请求浪费在必定搜不到的条目上。

**全盘快搜（Everything）**

- 左侧导航里的**独立入口**，不再挂在「剧集墙」下面；页面顶部显示当前检索通道，也可一键跳到「设置」配置。
- 优先调 `es.exe`，其次 Everything 的 HTTP 服务；两者都没配置时**自动降级**为媒体库内检索，所以功能始终可用。
- 想真正走全盘：把 Everything 官方的 `es.exe` 放到 `D:\tool\Everything\es.exe`（本机该目录目前只有 `Everything.exe`），或在 Everything 选项里启用 HTTP 服务，再到「设置 → 全盘快搜」填地址。
- 搜索结果里不在扫描库的文件也能直接播放，守护进程会留一条 `external` 记录。

**PotPlayer 软件内播放**

- 默认开启。点任意「播放 / 续播 / 从头播放」或快搜结果里的播放时，界面先展开「播放舞台」，再由 `app/embedded_player.py` 用纯 Win32 `SetParent` + `SetWindowPos` 把 PotPlayer 窗口嵌到主窗口里、按 `#playerHost` 的屏幕矩形（CSS 像素 × DPR）摆位。
- **全程不碰 `window.native`**：按 PID + 标题枚举主窗口 HWND，绕开非 UI 线程访问 WebView2 COM 控件会抛 `E_NOINTERFACE` 的问题。
- **失败即降级**：找不到主窗口、等不到 PotPlayer 窗口、`SetParent` / `SetWindowPos` 失败、非 Windows 平台，都会让 PotPlayer 照常在独立窗口播放，并提示降级原因，绝不会出现「点了没反应」。
- 内嵌后播放器不再是顶层窗口，`FindWindowW` 找不到它；因此把 HWND 写进 `settings.embed_hwnd`，**另一个进程**的托盘守护也能继续读进度、写会话。关闭主窗口或点「退出内嵌播放」都会把窗口还原成独立顶层窗口，不会留下孤儿子窗口。
- 右上角「内嵌播放」开关、设置页「在软件内播放 PotPlayer」两处都可关掉，改回原来的独立窗口播放。

### 中文名匹配机制（重要）

**只在三个动作里同步执行，没有任何定时任务、后台回填队列或待办文件：**

```
导入列表预览 / 扫描目录完成 / 用户点「重新匹配」
        ↓
内置离线词典（98 部作品的真实 Bangumi 对照，随代码自带）
        ↓ 未命中
本地已学词典（用户手动改过的中文名，优先级最高）
        ↓ 未命中且为外文名
在线 Bangumi 搜索（可配代理，1.5s/3s 短超时，失败整批快速降级）
        ↓
结果当场写入 name_alias / subjects / watched_list / media_files 并立即显示
```

- 数据来源 `app/data/aliases_builtin.json`，随版本库提交，**完全离线也能命中** `Attack on Titan → 进击的巨人`、`Frieren → 葬送的芙莉莲` 等。
- 本机直连 `api.bgm.tv` 实测超时，因此离线词典是主力；在「设置」里填代理后在线源自动生效。
- 带季数的标题优先显示该季中文名（如「更衣人偶坠入爱河 第二季」）；词典未收录该季时只给主标题中文名并标记「主标题匹配」，**不编造季名**，由你在预览里改一次即可永久记住。
- 用户手工修正永远优先于内置词典和在线结果。

### 播放记录与断点续播

- `potplayer.py` 用 Win32 `WM_USER` 消息回读总时长 / 当前位置 / 播放状态（实测有效），无需改 PotPlayer 设置、无需插件。
- `watcher.py` 每 3 秒轮询，按窗口标题切换自动结算会话；进度 ≥90%（可配）自动标记「已看完」。
- 续播用官方 `/seek=hh:mm:ss /current /autoplay` 精确跳转。
- 纠错操作「标记已看 / 标记未看 / 重置进度」只改进度表，**绝不删除观看会话历史**。

## 4. 数据存储

单文件 SQLite（WAL 模式），8 张表。**默认数据目录统一为 `D:\magicvideo`（`library.db` 在根下，封面在 `covers\`，日志在 `logs\`）**；只有 `./start --local` 用项目内 `data/library.db`、`dev.bat` 默认用 `data/dev/library.db` 安全副本。可用 `MAGIC_VIDEO_DATA_DIR` 覆盖。

> **两条独立的数据流**：`watch_progress` / `watch_sessions` 由托盘守护自动累积；`watched_list` 是你手动导入的清单快照，二者没有外键关联。想让已看完的播放记录出现在「看过的列表」，点该页的「从播放记录同步」按钮（幂等、只补 `completed=1`、不改写手动导入的行）。旧版解析器残留的脏标题（如《…》（ 年， ）。- 完）用同页「清洗脏数据」按钮一键修正。

| 表 | 用途 |
|---|---|
| `directories` | 已添加的扫描目录与上次扫描时间 |
| `media_files` | 扫描到的文件、文件名解析结果、中文名、季/集 |
| `subjects` | 作品级元数据（Bangumi ID、中文名、原名、季） |
| `watched_list` | 你导入的「看过的列表」 |
| `watch_progress` | 断点位置、百分比、完成标记、播放次数 |
| `watch_sessions` | 每次观看的起止时间与最远进度 |
| `name_alias` | 中英/中日对照词典（内置 + 用户修正） |
| `settings` | 播放器路径、轮询间隔、阈值、代理、主题、内嵌开关、`embed_hwnd`（内嵌播放器窗口句柄）等 |

`data/` 已被 `.gitignore` 排除，**不会进版本库、不会上传**。旧版本数据库升级只做 `ALTER TABLE ADD COLUMN`，不重建表、不丢已有播放记录。

## 5. 命令行

```bat
python cli.py init                      :: 初始化数据库并显示词典统计
python cli.py import seen.txt           :: 导入清单（即时匹配中文名）

python cli.py status                    :: 库统计 + 播放器实时状态 + 词典统计
python cli.py player                    :: 读取 PotPlayer 当前播放状态
python cli.py progress                  :: 列出所有断点进度
python cli.py mark 12 watched           :: 标记已看
python cli.py mark 12 unwatched         :: 标记未看（清续播点，保留历史）
python cli.py mark 12 reset             :: 重置进度
python cli.py match                     :: 重新匹配所有未识别标题
python cli.py dict                      :: 词典统计
python cli.py import-alias-file         :: 手动导入 data/alias_import.json
python cli.py autostart on|off          :: 开机自启开关
python cli.py daemon                    :: 前台启动托盘守护
python cli.py test                      :: 运行全部单元测试（结果写入 data/test_last.json）
python cli.py obsidian status           :: 查看 vault、笔记与最近测试状态
python cli.py obsidian sync             :: 同步流程与结果到 Obsidian
python cli.py obsidian path "D:\My Vault" :: 指定要写入的 vault
python cli.py obsidian open             :: 打开笔记目录
```

### Obsidian：自动记录流程与结果

v0.1.3 起，软件可以把**开发流程、自测结果、优化路线图、功能缺口**自动写进你本机 Obsidian 的一个独立文件夹
（默认 `Magic Video/`）：项目总览、版本记录、P0–P3 路线图、自测报告、缺口与决策、使用速查，外加按天追加的开发日志。

- **只读你已有的笔记、只写这个独立文件夹**；检测到多个 vault 时不会擅自猜，需要在「设置 → Obsidian 知识沉淀」里明确指定。
- 每篇笔记的「我的批注」区在同步时**原样保留**，可以直接在 Obsidian 里勾路线图、写想法、加标签。
- `run_tests.py` 会写 `data/test_last.json`，自测报告与结果时间线从中生成；开启「测试后自动同步」后 `cli.py test` 会自动留痕（默认关闭）。
- 笔记只有聚合统计与项目文档，**不含视频路径、文件名、观看明细**，也不依赖任何 Obsidian 插件或联网服务。

完整契约见 [`docs/OBSIDIAN.md`](docs/OBSIDIAN.md)；本机已接入 `C:\Users\Administrator\Documents\Obsidian Vault`。

## 8. 已知限制与后续建议

- 外部打开但尚未加入扫描目录的文件，只有窗口标题作为路径，需先「添加目录」才能续播。
- 在线刮削依赖网络可达性；不通时自动降级到离线词典，未命中的外文名可在导入预览里手动填一次。
- 封面抓取同样依赖站点可达与标题能对上；只有中文作品名命中率稳定，字幕组英文文件名 / 番号编号会跳过，没有封面的卡片显示占位图，不影响播放与记录。想补更多就在「剧集墙」再点一次「后台抓取封面」。
- Everything 全盘检索需要 `es.exe` 或 HTTP 服务，两者都没启用时自动降级为媒体库检索；本机 `D:\tool\Everything` 目前只有 `Everything.exe`。
- 软件内播放依赖 Win32 窗口嵌入，某些播放器皮肤 / 全屏模式可能需要点「重排画面」；任何失败都会自动切回独立窗口。
- 进度表目前以文件路径为主键，移动硬盘换盘后需要重新扫描（重定位向导已列入优化建议）。
- 同类软件调研与 14 条分优先级优化建议见 **`docs/OPTIMIZATION.md`**。
